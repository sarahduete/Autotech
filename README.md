# 🚗 AutoTech

**Projeto web voltado ao setor automotivo**

Projeto desenvolvido com a proposta de criar uma experiência digital relacionada ao segmento automotivo, trabalhando a apresentação das informações e a organização visual do site.

🔗 **[Acessar o site](https://autotech-lgtx.onrender.com/index.php)**

---

## 📖 Sobre o projeto

A ideia do AutoTech surgiu como uma oportunidade de desenvolver um projeto voltado ao setor automotivo, explorando uma identidade visual relacionada a esse segmento.

O objetivo foi trabalhar a estrutura de um site e organizar suas informações de forma clara, criando uma apresentação que combinasse com a proposta do projeto.

## 💻 Como foi desenvolvido

O desenvolvimento começou com o planejamento da estrutura e a definição da aparência visual do site.

Depois, trabalhei na organização das páginas e dos elementos que fariam parte da interface, buscando manter uma navegação simples e uma apresentação visual coerente com o tema automotivo.

Na etapa de estilização, trabalhei na organização dos elementos, nas cores, na tipografia e nos espaçamentos, ajustando o layout para manter uma aparência consistente.

Ao longo do desenvolvimento, realizei revisões para melhorar a apresentação do conteúdo e a organização da interface.

## ⚙️ Características do projeto

- Interface voltada ao segmento automotivo.
- Organização das informações.
- Identidade visual relacionada ao tema.
- Estrutura de páginas web.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- PHP
